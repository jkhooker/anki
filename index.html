Host for Free & Use on Computer + Android Phone

LexiForge Anki Studio is built as a 100% static Progressive Web App (PWA). It requires no paid backend server or database and can be hosted for free forever:

Option A: Netlify Drop (Fastest — 30 Seconds, No CLI Needed)

  1. Open app.netlify.com/drop in your browser.
  2. Drag and drop this project folder (anki-card-studio) onto the page.
  3. You immediately get a free https://your-name.netlify.app URL that works on both your computer and your Android phone!

Option B: GitHub Pages or Cloudflare Pages (Free Forever)

git init git add index.html index.css app.js phonetics-dict.js apkg-exporter.js manifest.webmanifest sw.js sample-arbre-de-noel.jpg git commit -m "Deploy LexiForge Anki Studio" # Push to a GitHub repository and enable Settings -> Pages (Deploy from branch: main)

Using on Your Android Phone + AnkiDroid

  • Install as an Android App: Open your hosted URL in Chrome on Android, tap the ⋮ menu → Add to Home screen / Install app.
  • One-Tap Import into AnkiDroid: Tap Export New Cards (.apkg) on your phone. When the .apkg file downloads, tap Open — AnkiDroid automatically imports the cards (and images) and merges them directly into your existing français, italiano, mandarin (正體字), and mandarin (簡化字) decks!

Pronunciation & Definition Engine Settings

By default, the app automatically generates [B] (IPA for français/italiano, Zhuyin for mandarin) and [C] (concise definitions in French, Italian, or English) using its built-in Wiktionary API & phonetic transducer with zero setup required.

If provided, clicking "Auto-Fill [B] & [C]" uses gemini-2.5-flash to tailor the concise definition to your exact context sentence. Leave blank to use the free built-in Wiktionary & phonetic engine.
